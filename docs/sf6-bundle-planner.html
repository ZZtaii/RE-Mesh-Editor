The four names people mix up

      

        
Mod Folder Name
The folder on your drive. A new variant needs a new folder name; reusing one updates that export instead. Example 11 Ingrid C1 Braid.

        
Display Name
What you read in Fluffy. Written as name=. Example Braid.

        
Bundle Name
Groups separate mods under one heading. Written as nameasbundle=. Same text on every variant, or they will not group.

        
Parent Mod
The menu this entry goes inside. Written as addonfor=. It must match the parent's Display Name exactly — it is not a folder path.

      

    


    

      
Worth knowing

      

        
The mesh decides the game path
The collection you pick supplies the character, costume and slot. Calling a folder “C2” will not turn a C1 mesh into costume 2.

        
Slots are 00 Head, 01 Body, 02 Hair
Costume folders keep three digits: 001, not 01.

        
Menu Only needs its Category typed
There is no mesh to read it from, so the exporter writes whatever is in the Category field — usually still there from your last export.

        
Create Parent Menu is a shortcut
Following this plan you never need it: each menu is made before anything points at it. Turn it on only when you name a Parent Mod that does not exist yet.

        
Descriptions break lines with \n
A literal backslash-n, not a slash. Each menu and option can also carry its own preview image.

        
Extra categories use semicolons
Hair; Colours becomes one category line each, on top of the character category.

      

    


    

      
If the exporter refuses

      

        
An add-on option must have a different display name from its parent mod.
Your Display Name and Parent Mod are the same text. Rename one of them.

        
The parent folder already belongs to a different mod.
Create Parent Menu found a folder that is not a matching menu. Point Parent Menu Folder somewhere new.

        
This folder belongs to a mesh mod. Choose a separate folder for the dummy menu.
A menu cannot reuse a mesh mod's folder. Give the menu its own.

        
The selected collection has no recognizable SF6 mesh filename.
The collection was not imported from an esfNNN_CCC_SS.mesh file. Re-import the original mesh and edit that.

        
Enter a folder name without leading/trailing spaces or a trailing dot.
Trim the Mod Folder Name. It also cannot contain \ / : * ? " < > |.
